# 🖥 Remote PC Control Bot (Telegram)

Telegram-бот для удаленного администрирования ПК под управлением Windows. Позволяет управлять компьютером прямо из чата Telegram, используя инлайн-кнопки.

## 🚀 Возможности

- 📸 **Скриншот экрана**: Мгновенный снимок рабочего стола.
- 📋 **Диспетчер задач**: Просмотр топ-процессов по потреблению RAM и их завершение по имени.
- 🪟 **Управление окнами**: Свернуть все окна или закрыть активное.
- 🔄 **Управление питанием**: Выключение или перезагрузка ПК с задержкой в 5 секунд.
- ⚙️ **Автозагрузка**: Копирование бота в `AppData` и добавление в реестр Windows (`HKCU\...\Run`).
- 🔒 **Безопасность**: Доступ к функциям имеет только владелец (проверка по `ADMIN_ID`).

## 🛠️ Технологии

- **Python 3.10+**
- **Aiogram 3.x** (Асинхронный фреймворк для Telegram Bot API)
- **Psutil** (Управление системными процессами)
- **Pillow** (Работа с изображениями и скриншотами)
- **PyAutoGUI** (Эмуляция нажатий клавиш)

## 📦 Установка и запуск

1. установить все библиотеки "pip install aiogram psutil pillow pyautogui"
2. получить токен бота и айди чата. 
3. Вписать в main.py
4. открыть cmd в папке remote control, вписать python main.py | Нажать старт в боте тг.
